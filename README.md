# Pure Python OOP Finance Tracker

A minimal project demonstrating Object-Oriented Programming (OOP) principles in Python without external or unnecessary standard libraries.

## Project Structure

- `log_mixin.py` - `LogMixin` (Multiple Inheritance)
- `transaction.py` - `Transaction` (Abstraction, Encapsulation, `@property`, `@staticmethod`, `@classmethod`, Magic Methods)
- `income.py` - `Income` (Single Inheritance, Polymorphism)
- `expense.py` - `Expense` (Single Inheritance, Polymorphism, `super()`)
- `subscription.py` - `Subscription` (Multilevel Inheritance, `@classmethod` alternative constructor)
- `card.py` - `VirtualCard` (Used in Composition)
- `wallet.py` - `Wallet` (Composition, Aggregation, `__len__`)
- `main.py` - Entry point
